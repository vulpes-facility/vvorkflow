# AGENTS.md

vvorkflow is a light desktop IDE for directing TUI coding agents across git worktrees, on a Rust engine and Tauri 2.\
Its owner uses it alone, for now: a main agent in a terminal directs worker agents, such as Codex and Claude Code, that run as their real TUIs.\
The project is at the design stage and has no app yet.

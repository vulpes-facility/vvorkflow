# Writing

1. Write `README.md`, the documents in `docs/`, and the agent instructions in English.
2. Write them in ASD-STE100 (Simplified Technical English).
3. Write the requirement levels with the BCP 14 keywords in upper case (RFC 2119, RFC 8174): MUST, MUST NOT, SHOULD, SHOULD NOT, and MAY.
4. Use Semantic Line Breaks for Readers ([SemBR4R](https://github.com/vulpes-facility/sembr4r)), and make the breaks show in the rendered output.\
   End each broken line with a `\`.\
   Do not put a `\` at the end of the last line of a paragraph or a list item.
